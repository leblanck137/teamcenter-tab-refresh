Teamcenter Tab Restorer

Privacy Policy

Last updated: November 16, 2026

Teamcenter Tab Restorer helps users return to previously open Teamcenter pages after Siemens authentication redirects. It saves limited navigation information in Chrome's local extension storage for that purpose only.

Information the extension processes

The extension records Teamcenter page URLs, browser tab identifiers, and timestamps associated with those URLs. A Teamcenter URL can include an internal object identifier and may reveal information about the page a user visited.

When a saved URL is unavailable, the extension may temporarily inspect a tab's existing navigation history to locate an earlier Teamcenter page. It also checks open tab addresses to identify Siemens login and session-end pages.

How the information is used

This information is used only to identify Teamcenter tabs affected by authentication redirects and restore them to the corresponding Teamcenter pages. It is not used for advertising, profiling, or analytics.

Storage and sharing

Saved information is stored locally in the user's Chrome extension storage. The extension does not send saved browsing information to the developer, advertising providers, analytics services, or other third parties and does not sell user data.

When a page is restored, Chrome connects to the relevant Teamcenter service as part of ordinary website navigation. The service may process those requests under its own policies.

Information not collected

The extension does not collect passwords, authentication credentials, or the contents of Teamcenter documents or webpages. Its navigation-history fallback is limited to selecting a previously visited page.

Retention and control

Saved page information is retained locally for tab restoration and associated records are removed when tabs are closed. Users can remove the extension and its locally stored data using Chrome's extension management controls.

Changes to this policy

If the extension's data practices change, this page will be updated accordingly.

Contact

For privacy-related questions, use the developer contact information shown in the extension's Chrome Web Store listing.

Teamcenter Tab Restorer is an independent tab restoration utility.
